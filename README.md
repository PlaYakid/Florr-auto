# 星际闪避 · Star Drift

一个无需安装依赖的 HTML 小游戏。驾驶飞船躲避陨石，收集星星，挑战最高纪录。

## 开始游戏

下载本仓库并用浏览器打开 `index.html` 即可游玩。所有样式和脚本均包含在文件中，无需联网或构建。

## 操作

- 方向键或 WASD：移动飞船。
- 鼠标按住拖动 / 手机触控拖动：控制飞船。
- P 或暂停按钮：暂停与继续。
- 收集星星获得 50 分，生存每秒获得 10 分；撞到陨石则结束。
- 难度随时间增加，最高分保存在当前浏览器中；切换窗口时自动暂停。

## 可选：在线游玩

如需在线网址，可在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支的 / (root) 目录并保存。部署成功后，地址通常为 https://playakid.github.io/Florr-auto/ 。本次代码上传没有启用 Pages。
